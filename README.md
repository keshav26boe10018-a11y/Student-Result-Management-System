# Student Result Management System

## Project Overview

The **Student Result Management System** is a simple Python-based project designed to calculate and display a student's academic result.

The project takes student details and marks of three subjects as input. It calculates the total marks, percentage, grade, and final pass/fail result.

This project is created using basic Python concepts such as variables, input/output, arithmetic operations, conditional statements, and logical operators.

## Features

* Enter student name
* Enter roll number
* Enter branch
* Enter marks for three subjects
* Calculate total marks
* Calculate percentage
* Calculate grade
* Check pass/fail result
* Display the complete student result

## Passing Criteria

Each subject has a maximum of **50 marks**.

A student must score at least **20 marks in each subject** to pass.

## Grade Criteria

| Percentage    | Grade |
| ------------- | ----- |
| 90% and above | A+    |
| 80% - 89%     | A     |
| 70% - 79%     | B     |
| 60% - 69%     | C     |
| 50% - 59%     | D     |
| Below 50%     | F     |

## How to Run

### Step 1

Install Python 3 on your computer.

### Step 2

Open the project folder in Visual Studio Code or another Python editor.

### Step 3

Open the main program:

```text

```

### Step 4

Run the program.

### Step 5
